A single run is not a measurement, roughly twenty tests flip sides between runs for reasons outside the tool, so the trend across thirteen runs is what counts. Almost none of the work widens a tolerance; it deletes a stray parameter or corrects a wrong assertion.

What we built to prove the typed path

The legacy path silently drops a parameter a test declares, runs the tool on defaults, and records the result as a pass. Every layer now has to go through the typed path before we can claim it works.

  • Async on by default. POST /api/jobs is the path the tool form takes. #23329, after #23084 aligned it with sync execution.
  • Selenium drives the real form. A harness that fills the actual tool form in a browser and submits it, pointed at the typed path so frontend bugs are no longer bypassed. #23347, #23372.
  • Framework tool tests run typed. The framework suite exercises the typed path instead of falling back, so parameter-model gaps surface in Galaxy's own CI.
  • Parameter model corrections. Multiple selects optional by default #23351, typed request value shapes #23414, conditional booleans #23431, legacy repeat synthesis removed #23170.

Twelve Galaxy PRs merged since July across the request path, the parameter model, and the three test layers.

Proposal: move the ecosystem to async

Async is the default in the upcoming release. The remaining work is the tool ecosystem, and we intend to do what it takes rather than keep the legacy path alive for it.

  • Run every repository against the typed path. tools-iuc first, then the usegalaxy.eu custom tool repositories, which are structured the same way.
  • Fix in batches. Grouped PRs of related packages rather than one per tool; at 155 remaining, per-tool PRs do not finish.
  • Separate deployment from tools. The dashboard cross-checks against the AnVIL deployment: 80 of the 111 shared tools fail only there, 3 fail on both.
