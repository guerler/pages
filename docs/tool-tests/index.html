--- layout: dashboard title: Tool tests description: Heatmap of tools-iuc tool-test results. nav_id: raster ---

Each row is a tool and each column is one full tools-iuc test-suite run using the typed tool-request path.

Columns are historical GitHub Actions runs at irregular intervals, so the gaps between them have no meaning. Run times are UTC. Color shows the result type and intensity shows the fraction of tests affected. Hover over a cell for exact numbers and click it for failing tests, tracebacks, and the CI run. Tools appear when they are first tested, so the row list grows over time. The bar above each column shows run coverage and affected tools, while the bar beside each row shows how often that tool had failures across the runs shown. Click either for details.
